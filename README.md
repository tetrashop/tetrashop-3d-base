## 🚀 نصب و راه‌اندازی

### پیش‌نیازها

- Node.js 16+\n- npm 7+

### نصب

```bash
git clone https://github.com/tetrashop/tetrashop-3d-base.git
cd tetrashop-3d-base
npm install
```

### اجرا

```bash
npm run dev
```
